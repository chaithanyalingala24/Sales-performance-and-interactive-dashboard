# Sales performace deep - dive Analysis and interactive Dashboard

## Overview
This Sales Data Dashboard helps analyze and visualize sales performance through interactive charts and key metrics. It provides insights into revenue, profit, sales trends, and product performance to support business decision-making.

## Features
- Track total sales and profit
- Analyze sales trends over time
- View top-performing products
- Compare sales across regions/categories
- Interactive filters and visualizations

## Dataset
The dashboard uses sales data containing information such as:
- Order ID
- Order Date
- Product Name
- Category
- Region
- Quantity Sold
- Sales Amount
- Profit

## Tools Used
- Power BI
- Microsoft Excel

## Key Insights
- Identify top-selling products
- Monitor monthly sales growth
- Compare regional performance
- Track profit and revenue trends

## Files included
- Sales data dashboard.pbix
- Sales_Dataset.csv

## Conclusion
The Sales Data Dashboard provides a clear view of business performance and helps stakeholders make data-driven decisions quickly and effectively.
